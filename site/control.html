        / 03AdvancedApprovals, other tailnets, modules

        Approvals

        Turning on the terminal, removing a hub and shutting down a device need confirmation from another hub. If too few hubs are online, the quorum drops.

        Quorum per action

        1 = you decide alone. 2 or 3 = one or two other hubs confirm in Control › Approvals.

        Other tailnets

        Pair with someone else's tailnet to share services and files. Code is never shared.

        Pair a tailnet

        On the other hub, run python -m core --peer-invite --url URL_OF_THAT_HUB and paste the invitation here.

        Version and updates

        Hub name

        The name other hubs see, and this device's Tailscale name. Changing it recreates the Serve routes and reloads the page. Stop public links first.

        Public login

        The login in front of this hub's public links. Changing it signs out current visitors.
